# astroorquesta-media

Hosting público de archivos de medios para el pipeline de publicación de [AstroOrquesta](https://github.com/nazuaje29/ContentCreator) (repo privado). Buffer necesita una URL pública, estable y HTTPS para cada asset al publicar — este repo cumple esa función sin exponer la VPS a internet.

No contiene código ni datos sensibles, solo archivos de imagen/video de marca. El contenido real (captions, lógica, credenciales) vive en el repo privado.
